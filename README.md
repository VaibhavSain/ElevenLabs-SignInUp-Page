# ElevenLabs-Inspired Sign In & Sign Up Page 🎨

A clean and modern **Sign In & Sign Up page inspired by ElevenLabs**, built from scratch using **HTML and CSS**.

This project focuses on creating a simple, responsive, and visually appealing authentication interface while improving frontend development and CSS skills.

👉 https://profound-paprenjak-6c6a89.netlify.app/

## ✨ Features

* 🔐 Sign In page
* 📝 Sign Up page
* 🎨 Clean and modern UI
* 📱 Responsive design
* ✨ Custom CSS styling
* 🧩 Simple and reusable HTML structure
* 💻 Beginner-friendly frontend project

## 🖥️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/elevenlabs-signin-signup.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd elevenlabs-signin-signup
```

### 3. Run the project

Open `index.html` directly in your browser.

You can also use **VS Code + Live Server** for a better development experience.
